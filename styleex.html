Full Download

Requirements: Windows, Linux or Android Device

Step 1
Open the Files.fm folder and download the ZIP file.
If you are on an Android device also download the Kiwi Browser APK. If you are on PC download or open any Chromium based browser.
Kiwi Browser APK download
Step 2
Open the Kiwi Browser (or any Chromium based browser on PC) and enter chrome://extensions in the search bar.
Step 3
Click "+ (from .zip/.crx/.user.js)" and select the downloaded ZIP file.
Step 4
Open the Groq API keys website on any browser (doesn't have to be Kiwi) and get a free API key.
! Note your API key somewhere !
Step 5
Open the website you want to edit on Kiwi Browser and click on the 3 dots on the bottom right and select "AI Web Customizer".
Enter your API key there and follow the instructions. Your API key gets saved in the browser so that you only have to enter it once.
